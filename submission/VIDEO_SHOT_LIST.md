# RESOLVEGRAPH — Video Production Shot List & Visual Direction
**Target Duration:** 2 Minutes 45 Seconds  
**Format:** Screen Recording (1080p 60fps) + Smooth Cursor Smoothing  
**Resolution:** 1920x1080 (16:9 Aspect Ratio)  
**Version:** 1.0.0 (November 2026)

---

## Technical Recording Guidelines
- **Browser**: Fullscreen Chrome window with bookmarks bar hidden.
- **Font Zoom**: Set browser zoom to **110%** for maximum legibility on mobile and tablet screens.
- **Mouse Pointer**: Enable subtle yellow click-highlight circle with smooth cursor movement.
- **Transitions**: 0.3s cross-dissolves between major scene transitions.
